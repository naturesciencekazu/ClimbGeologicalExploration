# 科学の山・温泉・旅行グレーディング

地学・化学・植物・氷河と気象の観点で、全国の山・温泉・旅行先を評価した静的サイトです。

- `index.html` 登山：科学の山グレーディング
- `onsen.html` 温泉：科学と温泉
- `travel.html` 旅行：科学と旅行
- `common.css` / `app.js` 共通のスタイルと表示処理

## 公開方法（GitHub Pages）
1. このフォルダの中身をリポジトリの直下に置いて push する
2. リポジトリの Settings → Pages → Branch を `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## データの編集
各HTMLの `window.PAGE = {...}` の `items` 配列に1件ずつ書かれています。
体力度は `ct`（コースタイム時間）・`km`・`up`・`dn`（累積登り・下り、km）から自動計算されます。
